## 23.09.2026 — сессия предпроекта

### Решения по архитектуре

1. **Имя проекта — O.S.A.** (Операционная Система Агента). Метафора осы: матка = LLM-инстанс, рабочие = ноды в mesh, гнездо = mesh из устройств, феромоны = общая память.

2. **MVP-скоуп зафиксирован**: голый runtime на этом ноуте (одна нода, она же матка). Агент общается с Minimax API, имеет CLI, пишет в SQLite. Без bare-metal, без mesh — это слои 2 и 3.

3. **LLM-стратегия**: Minimax на MVP (есть ключ, проверена, квоты хватает). Своя ~1B-модель подключается позже как альтернатива.

4. **Trust-модель установки — красная линия**: OSA ставится ТОЛЬКО при физическом присутствии владельца устройства. USB-кабель / флешка / SD-карта / USB-debug / PXE в локалке. Запрещены: самораспространение по сети, удалённая установка без явного согласия, auto-discovery чужих устройств в mesh. Trust = список fingerprint'ов разрешённых нод.

5. **Целевое железо нод**: любые устройства с возможностью подключения к сети/интернету — смартфоны с разбитым экраном (приоритет), планшеты, старые ноуты, десктопы, Raspberry Pi.

6. **Тип проекта**: хобби, без жёстких сроков. Разрабатывается параллельно с обучением своей 1B-модели на другом ПК.

7. **Стек MVP**: Python 3.11+, uv (не poetry), SQLite, typer, pydantic v2, httpx, structlog (опционально на M0). БЕЗ LangChain/AutoGen/CrewAI.

8. **Лицензия**: MIT, репо публичное на GitHub.

9. **Менеджер пакетов**: uv.

10. **Масштаб проекта по слоям**:
    - Слой 1 (MVP, сейчас): Runtime на одной машине
    - Слой 2 (после MVP): Bare-metal install на любое устройство
    - Слой 3 (далеко): Mesh из устройств, объединённых проводом

### Закрытые вопросы M0 (зафиксировано 23.09.2026)

- ✅ **Endpoint Minimax**: `https://api.minimax.io/v1` (по официальной документации platform.minimax.io). Альтернативы: Anthropic-compatible `/anthropic`, China-region `api.minimaxi.com`. Используем OpenAI-compatible на M0.
- ✅ **Thinking-параметр M3**: парсим `reasoning_content` в `LLMResponse.reasoning`. По умолчанию выключен (hello-world быстрее), управление через конфиг в M1a.
- ✅ **Pydantic-settings**: в M1a (на M0 хватит `resolve_api_key()` с ручным `os.getenv`).
- ✅ **Минимальная версия Python**: 3.11. CI тестирует 3.11 и 3.12.
- ✅ **Префикс env-переменных**: `OSA_*`.
- ✅ **MinimaxClient**: больше не наследник OpenAICompatClient — у Minimax специфика (thinking), наследование вводит в заблуждение.
- ✅ **API-ключ**: Михаил пришлёт отдельно. До этого — тесты на stub.
